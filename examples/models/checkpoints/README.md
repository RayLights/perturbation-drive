# Model Checkpoints

This directory is for storing example model checkpoints.

## Download

Model checkpoints have been removed from the repository to reduce clone size.

The `dave_90k_v1.h5` and other model files can be downloaded from:
https://drive.google.com/drive/folders/1_8v3NfX3j_holplmxNRuszirhGfUzVv4?usp=sharing

Place downloaded checkpoint files in this directory to use them with the model examples.

## Note

Model checkpoint files (*.h5) are ignored by git as per .gitignore configuration.
